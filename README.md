## 背景・課題・解決されること
1.開発背景  

　現代において私たちが本当に求めているものは、物質的な豊かさ以上に「他者からの承認」や「自己肯定感」であると感じる。  
 
　しかし、日々の生活の中で「わざわざ人に言うほどでもない、些細な頑張り」は、誰にも言えずに飲み込まれてしまいがちである。
 
　そんな小さな努力に光を当て、誰もが前向きになれる場所を作りたいと考えた。  

2.課題  

　- 「SNS疲れ」と「誹謗中傷」: 既存のSNSでは、他人の輝かしい投稿と自分を比べてしまい、逆に自信を失うことがある。また、ネット上の誹謗中傷や攻撃的な言葉にさらされ、心が疲弊してしまう。  
 
　-承認のハードルの高さ: 「朝、決めた時間に起きられた」「ゴミを拾った」といった些細な出来事は、リアルの友人には言いづらく、発信の場がない。  
 
　-「AIと話している感」への物足りなさ: AIチャットボットとの1対1の対話は、便利ではあるものの「温かみ」や「社会的な繋がり」を感じにくい。  

3.解決されること  

　-低い自己肯定感: すべての投稿に対して肯定的なフィードバックが返ってくるため、利用するたびに自信と生きる活力を得られる。  
 
 　-「SNS形式」による自然な体験: チャット形式ではなく「投稿」という形式をとることで、AIを意識せず「世界から認められている」という感覚を自然に演出。  
  
　-心の居場所づくり: 人に言うほどでもない些細な出来事を安心して吐き出せる場所を提供し、日常のストレスを軽減。

## プロダクト説明
本製品は、AI技術を活用した「全肯定型SNS風プラットフォーム」である。

1.パラメータによる自分好みの返信設定

　肯定・共感・批判の3つのパラメータが存在し、それらの割合を自分で調節可能

2.「多種多様なユーザー」の演出

　AIの返信は、単なるテキスト生成ではなく、独立したSNSユーザーとして振る舞う。

　各ユーザー(AI)には独自のパラメーターが設定されており、語尾、言葉遣い、性格、反応の傾向が異なるため、より高度な没入感を提供する。

3.お気に入り機能

　返信の保存: 心に刺さったお気に入りの返信は保存することができ、一覧画面からいつでも見返すことが可能。

4.お気に入りユーザーとの個別対話

　タイムライン上で特に自分好みの返信をくれたユーザーとは、個別にチャット（DM形式）することが可能。

「もっとこの人に褒めてほしい」「この人のアドバイスが心に刺さる」といった、よりパーソナルで深い繋がりを体験できる。

### アイデア面  
-発案時点：「効率」ではなく「肯定」を追求

　➙多くのアプリが「日常の効率化」を目指す中で、私たちは「日常を生きるための活力＝自己肯定感」こそが、現代人に最も必要なものであると考えた。

-多様なパラメータ設定(肯定・共感・批判)

-名称の由来: 視点を変える「見方」と、常にあなたの側にいる「味方」のダブルミーニング  

### デザイン面
1.アプリ内デザイン  
　色彩心理学に基づいたモード設計  
　視覚情報が感情に与える影響を考慮し、モードごとにテーマカラーを設定  
　　-褒め: 安心感を与える「ピンク（暖色）」  
　　-中間: 穏やかな「グリーン」  
　　-厳しめ: 冷静になれる「ブルー」
  
2.アイコンデザイン    
 　　-自身の見方を変えるという意味の「目」は見守られている安心感も与え、繋がった「手」や「ハート」の曲線で味方がいる心強さを表現  
   　　-キャッチーで印象的であること、多彩なモードを複数のカラーで表現しつつ、本来の目的である「安心感」を重視したデザイン
